# Phase One Capstone Project

This is a simple Java project for an IgirePay account transaction system. It shows how customers can have different account types, such as wallet and savings accounts, and how transactions are processed.

## Features

- Create a customer with multiple accounts
- Deposit and withdraw money
- Track successful transaction history
- Reject duplicate transaction references
- Record failed transactions
- Apply savings account withdrawal rules and fees

## How to Run

use console to run


The main demo is in `src/main/java/com/igirepay/Main.java`.
